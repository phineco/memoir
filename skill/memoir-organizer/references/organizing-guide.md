# 整理规则详解（memoir-organizer）

本文件是 SKILL.md 的详细规则后盾：触发 skill 后按此执行。

## 一、输入处理

### 0. 讲述者确认（每次整理/采访的第一步，先于一切）
- 先问清"这次是谁讲的？"，拿到讲述人姓名。用户在初次使用 skill 时会被要求提供姓名，之后默认沿用，可随时更换。
- 必须把讲述人对应到家族树上的具体人物：
  - 能唯一对应 → 记 `narrator_person_id`（树上 person-id）+ `narrator_name`（全名），并记下讲述人与讲述对象的关系（如"本人讲述"、"女儿补充回忆"）；
  - 只有称谓（如"三叔"）→ 追问确认全名后再对应；
  - 树上没有这个人 → 走 🆕 新人物流程，问是否入树；用户说先不入树 → `narrator_name` 记原文称谓，`narrator_person_id` 留空，并在待核实清单里记一笔；
  - 实在无法确认 → `narrator_name` 记原文，`narrator_person_id` 空，进待核实。
- 绝不虚构讲述人身份；不确定就空着 + 标记，不编一个名字填上。
- 讲述人信息随初稿包进入 sync-json（`interview_upsert.payload.narrator_person_id` / `narrator_name`），同步到云端后网页自动显示"讲述者"。

- 文字稿即原文，可能含口头禅（"那个""然后""就是说"）、重复、语序混乱。先在心里做"保真清洗"：只顺语句，不动事实。
- 若文字稿来自 ASR 且有明显乱码段，标记 `[转写存疑]`，不要猜测还原。

## 二、四件套产出规则

### 1. 润色初稿（draft）

- 分段：按场景/时间自然分段，每段一个小场景。
- 只做三件事：顺语句、去口头禅、补必要的连接词。
- 禁止：添加原文没有的情节、对话、心理活动；合并两个不同时间的事；"美化"苦难或拔高评价。

### 2. 原话金句（quotes）

- 3–6 条，标准：有画面感，或有情感冲击力，或一句话能代表这个人。
- 必须是原话，可截短（用"…"连接），不得改写、不得拼凑两句。
- 例："一年到头吃不上一顿肉。""我娘站在村口看了很久。"

### 3. 待核实清单（verification_items）

触发条件（满足一条就列出）：
- 人名：只出现称谓（"三叔""大哥""我爹"）而无全名 → 核实全名及与讲述人的关系；
- 地名：只有"乡下""县城"等模糊词 → 核实具体村名/县名；
- 时间：只有"有一年""那时候" → 核实年份或与已知事件的先后关系；
- 数字：家庭人口、金额等与其他讲述矛盾或不完整 → 核实；
- 事件：转折处缺原因（"后来就搬走了"）→ 可列为"下次追问"而非核实。

每条格式：`❓ 「原文片段」→ 需要核实：……`

### 4. 时间轴（timeline）

- 抽取事件，按时间先后排列；时间不明写"小时候/年轻时"等原文标签，不要编年份。
- 格式：`时间标签 → 事件一句话`。

### 5. 故事时间段与关联人物（story period & related persons）

每次生成故事时必须给出，方便以后按时间线、人物线串联：

- **故事时间段**：本篇故事覆盖的起止时间。格式 `起 → 止（精度）`，精度 year/month/day；只知道大概写年份（如 `1978 → 1990（年精度）`）；跨度不明写"时间不明"，不要编。
  - 规则：取故事中最早和最晚两个**有依据**的时间点；依据不足宁可写"不明"。
- **关联人物**：除讲述对象外，本篇还关联到树上的哪些人。格式 `姓名（关系/角色）`，如 `王秀兰（讲述人）`、`李桂香（奶奶，故事中被提及）`；树外人物走新人物流程（标记 🆕）。
  - 讲述对象本人也要列出，角色标"讲述对象"。

## 三、核实循环

1. 首次输出四件套后，主动说："上面 ❓ 的几条麻烦确认一下，确认完我出定稿。"
2. 用户逐条回复后：有修正 → 更新初稿对应处；确认无误 → 该条标记 ✅。
3. 全部确认后输出定稿 + 一句话总结（如"本篇归入：1960s · 童年"）。

## 五、完整示例（输入 → 输出）

**输入**（讲述人：王秀兰）：
"我小时候家里穷，一年到头吃不上一顿肉。1968年那会儿，我们住在山东临沂乡下，家里五口人，就靠我爹一个人种地。三叔在县城的供销社上班，偶尔会带回来一些糖块，那是我最盼着的日子。有一年冬天特别冷，村里的井都冻上了，我娘每天天不亮就去挑水，手上全是冻疮。后来，1972年我大哥去当兵了，家里才稍微松快一点。我记得大哥走的那天，我娘站在村口看了很久。"

**输出**：
- 初稿：按"家贫/三叔的糖/冬天的井/大哥当兵"分四段，顺语句。
- 金句："一年到头吃不上一顿肉。""偶尔会带回来一些糖块，那是我最盼着的日子。""我娘每天天不亮就去挑水，手上全是冻疮。""我娘站在村口看了很久。"
- 待核实：❓「家里五口人」→ 只提到爹、娘、大哥和讲述人四人，第五位是谁？❓「山东临沂乡下」→ 具体是哪个村？❓「三叔」→ 全名？哪个县城的供销社？❓「有一年冬天」→ 具体年份？❓「1972年我大哥去当兵」→ 大哥姓名、入伍去向？
- 时间轴：小时候 → 家贫；1968年 → 住临沂乡下；有一年冬天 → 井冻上、娘挑水；1972年 → 大哥当兵。
