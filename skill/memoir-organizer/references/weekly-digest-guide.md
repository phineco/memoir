# 每周汇总（周报）模式规则（memoir-organizer）

目标：阶段性出成果——把一周的整理内容集中展示，并让一家人参与纠正修改。

## 一、收集本周内容（两种方式）

- **A. 同一对话连续整理**：用户直接说"生成本周周报"，从对话历史里汇总本周所有初稿包。最省事，推荐一周内的几次整理都在一个聊天里做。
- **B. 分散在不同对话**：用户把本周的初稿包（Markdown）逐份粘贴进来，说"这是本周全部"，确认收齐后再生成周报。

## 二、周报模板

```markdown
# 《XX 家庭 · 回忆录周报》（10月13日–10月19日）

## 本周新增故事（X 篇）
- 《篇名》· 讲述人 · 一句话摘要

## 本周金句
- …（3–6 条）

## ❓ 待全家核实
1. 「原文片段」→ 要核实什么（来自《篇名》）
2. …

## 🆕 本周新出现人物
- 姓名/称谓 · 上下文 · 是否已入树

## 家族树更新
- 王建军：⏳待采访 → 📝整理中
```

## 三、家人纠正协议（附在周报末尾，直接发给家人看）

> 家人们，帮忙核对带 ❓ 的条目，按编号回复就行：
> - `3. 三叔全名叫王建军 ✅`（确认）
> - `5. 不是1968年，是1969年 ✏️`（修正）
> - `7. 这个我也不清楚 ❓`（跳过）
> 不确定的空着就行，不用猜。

## 四、应用修正

用户把家人的回复粘贴回来（说"这是家人的核对回复"），skill 按编号逐条处理：

- ✅ 确认 → 该条标已核实，更新初稿对应处；
- ✏️ 修正 → 用新信息更新初稿，记一条"已修正"；
- ❓ 不清楚 → 保留，标注"待下次采访追问"。

然后输出**修正版周报**，并汇总："本次更新 X 条，还剩 Y 条待核实。"

## 五、本周定稿

待核实全部解决（或用户说"剩下的先放放"）→ 输出**本周定稿包**：定稿初稿全文（按人物/时间排序）+ 本周金句定稿 + 家族树最新版。可直接存档，后续进书稿或网站。

## 六、如实边界

- skill 本身不存数据，"一周"的内容靠 A/B 两种方式收集；跨周 continuity 靠用户把上周定稿包存好。
- 网站已有周报页（按周汇总已发布故事、金句、待核实），与本流程并行：已同步入库的内容以网站周报为准；本流程处理的是尚未入库或分散在对话里的初稿包，两者不要混为一谈。
